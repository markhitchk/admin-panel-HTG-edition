# Included Harley-The-Gamer Logo Assets

- `HTG.png` — original uploaded puppy logo, used as the built-in admin header fallback.
- `HTG-logo-vector.svg` — editable vector-traced version.
- `HTG-logo-exact.svg` — exact-look SVG wrapper preserving the original artwork.

The theme embeds `HTG.png` directly in the compiled admin CSS, so it works without an external image host. Administrators may override it with the **Branding — Header logo URL** setting.
